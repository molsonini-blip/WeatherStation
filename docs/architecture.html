Why UDP first

The hub broadcasts on your network for free, with no rate limits and no internet needed, so wind gusts and lightning arrive within seconds. The cloud is only the backup path and the source for forecasts and history.

One file holds everything

All readings, YoLink history, daily summaries and the activity log live in one SQLite file, which makes the nightly backup a single copy to ReadySHARE.

What reaches the internet

Only outbound HTTPS calls (Tempest, NWS, YoLink, IFTTT). Nothing on the EdgeXpert is opened to the internet; you reach the dashboard through Tailscale.
